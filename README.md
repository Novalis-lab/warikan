# 割り勘計算

合計金額と人数を入れるだけで、ひとりいくらかがすぐわかる Web ツールです。

公開URL：https://novalis-lab.github.io/warikan/

## できること

- 合計金額と人数から、1人あたりの金額を計算（全角数字・カンマ入りもOK）
- 多め・少なめ：「多めに払う人」「少なめの人」「ごちそうになる人」などのグループを追加して、1人いくら払うかをスライダーで決められる（100円きざみ）。残りを「普通」の人で等分する
- 何円単位で集めるか（1／10／100／500／1000円）
- 端数の扱い：「多めに集める（切り上げ・余りは幹事へ）」か「幹事が負担（切り捨て・不足は幹事が払う）」
- 結果をコピー・LINEで送る

## ファイルの役割

| ファイル | 役割 |
|---|---|
| `index.html` | 画面・色・計算のすべて（この1ファイルだけ） |

- グループを追加したときの名前と、最初に入る目安の額（「普通」の人の何倍か）は、`index.html` の中の `PRESETS` で変えられる
- スライダーのきざみ（100円）は `STEP` で変えられる
- 入力した金額や人数はどこにも送信しません。端数の設定（何円単位・切り上げ／幹事負担）だけ、この端末のブラウザに保存します
- フォント・角の丸み・アイコンは、トップページ（novalis-lab.github.io）の共通ファイルを読み込んでいます
